        No sign-up. No cloud.

        Open it and you're visible
        Each device gets a random name like Brisk Otter. Anyone on the same Wi‑Fi who opens Flick sees it, and sees what you share with everyone.
        Files go directly
        Everything travels over an encrypted WebRTC connection from one browser to the other. Nothing is uploaded or stored anywhere.
        Brokers only make the introduction
        Free public MQTT brokers pass a short handshake so two browsers can find each other. It is encrypted before it leaves the page, and your files and text never go through them.
        How it finds your Wi‑Fi
        Flick asks ipify.org for your network's public address and turns it into a scrambled meeting point. Devices behind the same router land in the same place.
        Different networks
        Share a link or QR code. Whoever opens it joins you directly, from any network.
        Keep both pages open
        Transfers run while both tabs are open. Received files are held in memory until you save them, so very large files work best on a computer.
